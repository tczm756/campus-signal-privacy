二、游戏原型处理的信息

核心玩法为离线单机，拒绝 TapTap 登录和对应隐私授权后仍可游玩。当前未设置广告、充值、内购、聊天、云存档或玩家内容上传功能，也未接入向玩家提供内容的在线生成式 AI 服务。

游戏在设备本地保存“减少干扰”画面设置和你同意的隐私政策版本，用于保留选择及判断是否需要重新征求同意。当前不将这两项设置上传给我们。你可以在游戏内修改画面设置或撤回 TapTap 授权；安卓版本发布后，也可通过系统的应用存储管理清除本地数据，可能同时重置设置及 SDK 登录缓存，具体以设备系统为准。

当前未设计收集姓名、手机号、身份证号、精确位置、通讯录、相册或录音的功能。可选 TapSDK 登录涉及的设备、网络及账号信息见下表；因此本政策不承诺“接入 SDK 后完全不联网或不处理个人信息”。最终安卓安装包尚待权限、SDK 和网络行为核验，这里的说明不作为对尚未发布包体的检测结论。

三、可选 TapSDK 与第三方清单

本轮开发工程接入 TapSDK Core / Login 4.11.1，正式安卓版本尚未开放下载。只有你主动选择 TapTap 登录，并同意本政策后，游戏才调用 SDK 初始化；初始化成功后才发起或恢复登录。没有预先勾选同意，拒绝不会启动该 SDK，也不会阻止离线游玩。

四、未来广告功能的边界

目前没有广告 SDK，也不会请求或展示广告。我们在评估后续版本接入广告的可能性，尚未确定或启用广告网络、广告位和数据处理配置。

若以后接入 TapADN 或其他广告 SDK，将在启用前更新本页，逐项披露实际提供方、SDK 版本、使用目的、信息种类、触发时机、权限、缓存或保存方式和官方隐私链接；如采用聚合广告，还会逐一说明实际接入的各家 SDK。根据法律要求重新征求必要的同意，不会将本次 TapTap 登录同意视为未来广告的数据处理授权。

广告标识符、个性化推荐及可选信息采集将按实际 SDK 能力单独控制。需要系统权限时先说明用途，再依法申请，拒绝可选授权不应阻止使用无关的离线功能。若加入激励广告，其观看与奖励规则将在实际功能中说明。

五、政策网页与下载平台

本政策网页为静态文本页面，没有由我们添加的统计脚本、广告、追踪像素、表单、Cookie 或浏览器本地存储代码，也不加载外部字体、图片或脚本。

本独立网页由 GitHub Pages 托管。访问时，浏览器必须向托管服务传输 IP 地址、请求时间、页面地址及随请求附带的信息。托管服务可能为页面传输、安全防护和故障排查处理技术日志，其基础设施可能位于中国大陆境外。具体保存与处理方式见 GitHub 隐私声明。游戏本地设置不会因访问此页而上传，我们不将页面访问技术信息用于广告画像。

你在 TapTap 等第三方平台进行预约、登录、评论或下载时，由相应平台按其隐私政策处理信息。我们不因你预约游戏而取得联系方式；游戏内可选登录的数据处理范围仅限前述 SDK 清单及你实际选择的授权。

六、主动联系时提供的信息

当你通过邮箱联系时，我们会收到你的发件邮箱、邮件正文以及你主动附上的文件，仅用于回复问题、排查故障、处理隐私请求或履行法律义务。请勿发送密码、验证码、完整身份证件或与问题无关的敏感信息；截图中的个人信息请先遮挡。

我们只在处理上述事项所必要的期限内保存邮件及附件；事项结束且无法定留存义务时，将删除不再需要的信息。邮件的收发服务也会处理必要的通信信息，其独立处理行为适用相应邮件服务的政策。

七、信息的保存、提供与安全

游戏本地设置、同意记录及 SDK 登录缓存保存在设备；我们未建立玩家资料或存档服务器。可选登录涉及的信息由 TapSDK 按其官方政策处理；网页托管和邮件服务处理各自必要的技术或通信信息。我们不使用网站托管或邮件服务存放、同步游戏存档。

我们不出售你的个人信息，也不为广告或营销向第三方提供你联系时提交的信息。除为处理你提出的事项而依法委托服务、取得你的单独同意，或履行法定义务外，不向其他主体提供这些信息。依法委托处理时，我们将要求受托方在约定目的和必要范围内处理并采取保护措施。

我们会限制对咨询邮件的访问、保护服务账号，并尽量减少信息留存。发生可能影响个人信息安全的事件时，我们将采取处置措施，并依照适用法律履行告知及报告义务。

八、你的选择与权利

你可以修改或清除本地设置，退出游戏内 TapTap 登录，或按上文方式撤回同意。对于你主动提供给我们的信息，可通过隐私邮箱申请查阅、复制、更正、补充或删除，撤回基于同意的处理授权，或要求说明处理规则。本游戏没有另建账号注册系统，TapTap 账号注销由平台受理；与 SDK 有关的权利请求也可通过我们协助转达。

请说明请求内容，我们将在必要范围内核验身份，优先通过原联系邮箱核对，不要求提供与请求无关的信息。通常在收到请求后的十五个工作日内回复；复杂情形需要延长时将说明原因。法律另有规定的，从其规定。依法不能立即删除的信息，将限制在法定目的内处理。

九、未成年人保护

平台当前登记的适龄提示为 12+，这不代表游戏已取得正式发行许可，也不替代未成年人个人信息保护要求。未成年人应在监护人指导下了解本政策并合理安排游戏时间。

我们不主动要求未成年人提交个人信息。不满十四周岁的用户如需通过邮件提供个人信息，应由监护人代为联系并依法取得监护人同意。监护人发现未成年人未经同意向我们提供信息时，可联系隐私邮箱申请核实、停止处理及删除；核实后我们将及时处理，法律要求保留的除外。

十、政策更新

本政策将随游戏实际功能更新。若将来增加账号授权范围，或启用统计、广告、支付、实名或防沉迷服务，将在功能启用前补充具体处理目的、信息种类、第三方信息及你的权利，并依法履行告知和同意程序。发生重大变化时，游戏将适当提示，需重新同意的将更新本机记录所对应的政策版本，不以更新文档代替依法需要的同意。
